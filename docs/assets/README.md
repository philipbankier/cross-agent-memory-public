# README Visuals

`overview.svg` is the editable project masthead and source/node/client diagram. The palette is
graphite, white, lime and muted teal; system typography keeps it self-contained. It uses no
external assets, tracking, provider logos or implied provider affiliation.

`evidence-flow.svg` is an explicitly illustrative Atlas example. It distinguishes proposals,
decisions and reported work. It is not a screenshot, generated answer or benchmark claim.

`architecture.svg` is the detailed, self-contained source-to-answer diagram. The README
displays the SVG without relying on GitHub's embedded diagram service. Edit its labeled
source-to-node-to-assistant flow when changing the architecture.

`control-panel.jpg` shows the actual local control panel with invented Atlas conversations
from three native source families. It is a product illustration, not a live deployment,
all-source coverage, answer-quality or authentication proof. No operator history is used.

When replacing screenshots, use a disposable synthetic node. Keep account identifiers,
credentials, personal paths, raw receipts and browser chrome out of the image. Keep the
README caption and alternative text explicit about synthetic data. Do not retouch the UI
or add controls that the application does not have.
